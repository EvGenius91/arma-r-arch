Через него регистрируются все объекты которые создаются в мире. Будь то техника, элементы инвентаря

## Методы:
### registerEntityBuy
сигнатура: registerEntityBuy(Entity entity, string shopUid, string accountUid): string
entity - объект сущности;
shopUid - идентификатор магазина;
accountUid - идентификатор аккаунта который осуществил покупку

Описание:
Метод  отправляет запрос на бекенд в ответ получает id сущности. Этот uid он записывает в свойство сущности

### **registerRemoveEntity
сигнатура: registerRemoveEntity entity, ReasonEnum reason): void
entity - объект сущности;
reason - одна из причин удаления сущности (продажа, уничтожение)

Описание
Метод регистрирует удаление объекта.
Отправляет запрос на бекенд с uid сущности. Бекенд регистрирует удаление сущности
