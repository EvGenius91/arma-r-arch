Осуществляет выполнение команд пришедших с бекенда. Воркер делает запросы каждую секунду на бекенд и получает от него команды которые необходимо выполнить на игровом сервере. Команды приходят пачкой. Игровой сервер обязан по каждой команде вернуть отчет о выполении. Если не возможно выполнить то возвращает описание причины

## Методы

Run(): void;
Этот метод вызывается после инициализации всех систем мира. В нем цикл который каждую секунду запрашивает команды с бекенда и выполняет их на игровом сервере

ForceRefresh(): void;
В отличии от Run сразу запрашивает команды из очереди бекенда и выполняет их
